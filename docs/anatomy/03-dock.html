NOTES:(UNLESS OTHERWISE SPECIFIED)
  1. Do not scale from screen. Read the numbers. CSS px @ 1×, dark theme.
  2. Widgets are independent cards, never one shared bar; bottom-aligned so collapsed widgets keep the shared baseline.
  3. Height SLOTS is fixed; the .min state collapses a widget to its header only (height auto).
  4. Composition: operator pins lead, TALON slots follow (max 3), leftovers last. An unused slot stays empty.
 
  1. by-talon widgets carry a 6px square before the title, a reason line in the header, and a violet-tinted border.
  2. Feed widget drops the glass over the media body; the header stays glass; an inset hairline bounds the media.
  3. Strip clips at 1280: the dock-more pill counts clipped widgets and scrolls them into view (verify-guarded).
  4. Calm mode restacks the strip as a 340px left column from CHAT-TOP (dashed in plan).
